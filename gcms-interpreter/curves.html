工具 气相强度曲线 方法与来源

查看 315 个香料物质在空气中的浓度与气味强度的关系，并把气相浓度换算成强度等级。

浓度为空气中（气相）浓度，数据来自调香师和训练有素的评价员的嗅闻评价。

不适用于水、乳等介质中的浓度，也不能用 OAV 或相对气味活性值换算。

    浓度换算

    数据来源与计算方法

    数据来自 Wakayama H, Sakasai M, Yoshikawa K, Inoue M. Method for Predicting Odor Intensity of Perfumery Raw Materials Using Dose-Response Curve Database. Ind. Eng. Chem. Res. 2019, 58(32): 15036-15044，doi: 10.1021/acs.iecr.9b01225。314 个物质的参数取自补充材料 Table S2，异戊酸取自正文 Table 3。

    曲线公式：Ψ = Imax / (1 + exp(-(X - C) / D))，X 为 log10（气相浓度，μg/L 空气）。阈值为 Ψ = 1.4（刚能察觉）时的浓度：X = C - D · ln((Imax - 1.4) / 1.4)。

    强度标尺为标记量值标尺（LMS，0 到 100）：刚能察觉 1.4，弱 6.1，中等 17.2，强 35.4，很强 53.3，能想象的最强 100。

    横轴范围 -5 到 5 与原文作图范围相同；超出这个范围不给出换算值。D 小于 0.1 的 5 个物质（如香兰素）曲线近似阶跃，可以搜到，但不画曲线，也不提供换算。

    曲线是对评价数据的拟合结果。原文没有给出每个物质实测的浓度范围，横轴 -5 到 5 是原文的作图范围，离实测浓度较远的部分属于外推。浓度超过该物质在室温下的饱和蒸气浓度时，实际达不到，换算值没有意义。例如芳樟醇在 25 ℃ 空气中的饱和浓度约为 1300 μg/L（X≈3）。

    中文名只给常见物质，商品名保留英文。
