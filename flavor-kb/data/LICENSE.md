# Data license

`compounds.json` and `foods.json` contain data derived from FlavorDB2 (Garg N, et al., Nucleic Acids Res. 2018, 46, D1210-D1216, https://cosylab.iiitd.edu.in/flavordb2/), licensed under Creative Commons Attribution-NonCommercial-ShareAlike 3.0 (https://creativecommons.org/licenses/by-nc-sa/3.0/). These derived data are shared under the same license.

Key food odorant statements are short citations from the main text of Dunkel et al., Angew. Chem. Int. Ed. 2014, 53, 7124-7143 (doi:10.1002/anie.201309508), each with its page number.

Compound names, structures and synonyms were retrieved from PubChem (https://pubchem.ncbi.nlm.nih.gov/).
